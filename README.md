# redux-todo-app

<p>redux-todo-app is a React.js application with the implementation of a Todo App with Redux</p>

## Features
- useRef
- useContext
- custom useHook
- custom notification
- react-redux
- reduxjs/toolkit
- react-icons
- style-components
- custom preloader

### To install dependencies
```shell
npm install
```
or
```shell
yarn or yarn install
```
### To run the app
```shell
npm run start
```
or

```shell
yarn start
```

### Build the app
```shell
npm run build
```
or

```shell
yarn build
```
